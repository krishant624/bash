# Bash

A visual course for the Bash you type on a Linux host. It follows the same path as a short command list, then stays longer on the ideas that list skips: pipes, globs, links, find, PATH, quotes, exit status, and why `chown` fails when you are not root.

Each lesson is its own page, with a diagram and a practice terminal. The terminal is a computer drawn in the page. It is not your PC, and it never touches the files on the machine you are reading on.

[Download the full lesson guide](https://github.com/krishant624/bash/archive/refs/heads/main.zip)

Unzip the file and open `index.html`.
