Write and install a crontab

Point of this page. A crontab line is five time fields and a command. Lists, ranges, and steps cover most schedules. crontab - installs a table from standard input.

1-5 in the day-of-week field means Monday to Friday. 0,30 in the minute field means on the hour and half past. */15 means every 15 minutes. @reboot, @daily, and @weekly are shortcuts.

(crontab -l; echo 'line') | crontab - appends a line without opening an editor, which suits scripts. crontab refuses a table with a bad field and keeps the old one. /etc/crontab and /etc/cron.d have a sixth field, the user.

Cron mails output to the user, or drops it. Redirect each job: >> /home/ana/backup.log 2>&1, so a failure leaves a trace you can read.

LineRuns
*/15 * * * *every 15 minutes
0 2 * * *02:00 every day
30 6 * * 1-506:30 Monday to Friday
0 0 1 * *midnight on the 1st
@rebootonce at boot

Worked example

$ crontab -l
# m h dom mon dow command
*/5 * * * * du -sh /home/ana/work
$ (crontab -l; echo '30 2 * * 1-5 /home/ana/backup.sh >> /home/ana/backup.log 2>&1') | crontab -
$ crontab -l
# m h dom mon dow command
*/5 * * * * du -sh /home/ana/work
30 2 * * 1-5 /home/ana/backup.sh >> /home/ana/backup.log 2>&1
$ echo '61 * * * * date' | crontab -
"-":1: bad minute
errors in crontab file, can't install.
$ cat /etc/crontab
# /etc/crontab: system-wide crontab. This one has a user field.
SHELL=/bin/sh
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
# m  h  dom mon dow user  command
17 *  *   *   *   root  cd / && run-parts --report /etc/cron.hourly
25 6  *   *   *   root  test -x /usr/sbin/anacron || run-parts --report /etc/cron.daily
MistakeA job that works in your shell and fails in cron, because cron's PATH is short. Use full paths, or set PATH at the top of the crontab.
